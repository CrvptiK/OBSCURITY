## Documentation



### Start of Project

After the initial conceptualising; idea, research, rough planning and preparations, and
realising I was not gonna program a game, but rather conceptualising one and creating a
trailer, I got to actually producing some art for the trailer. (Post-project-note: Good thinking,
this was already enough work to kill me outright)



### First Steps

![Storyboard ink on paper](https://github.com/CrvptiK/OBSCURITY/blob/main/assets/progress/Storyboard.JPEG)

Art, art and more art: The first works consisted of storyboarding and asset creation.
The main art was created on iPad, drawn over the course of roughly 4 weeks, including static
pngs, video clips, frame by frame image sequences and animation created using ToonSquid.
(For all assets, see GitHub, or the assets folder in the zip-file)

![Sketches ink on paper](https://github.com/CrvptiK/OBSCURITY/blob/main/assets/progress/Sketches.JPEG)

Sound production and gathering, including music and sound effects: Using Audacity and
trying out LMMS (though not getting very far on that front), as well as scouring no-copyright
content on YouTube and pixabay, I gathered all the sounds I would need.



### Trailer Production

This is where a lot of work began for me. I am not the best editor and because I was working
with a lot of frame-by-frame I chose a very simple software to edit on. CapCut.
Best and worst decision ever. With many features locked behind a paywall, as well as the
software essentially bombarding its user with AI-features (which I refuse to even glance at,
but which haunted my entire editing process) it got on my nerve a lot.


On the other hand, editing is made very simple with CapCut, in contrast to using
DavinciResolve, which I only used for tiny adjustments in colour and sound. This is most
likely due to the fact I am more familiar with the former, but I spent several hours editing,
even though I am familiar with it.

While finalising the trailer, I set up a GitHub for all the content otherwise missed and to have
a nicer overview. I added the supplementary text, long written by the time the GitHub was set

finally finished the making of the trailer.
