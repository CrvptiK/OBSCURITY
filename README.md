### Project Description
<br>
OBSCURITY is a small, fast paced point-and-click game, focused around our digital footprint and the action we can take to protect our data. Randomly appearing cameras need to be clicked on time to prevent the player’s Obscurity rating from dropping. When this score reaches zero, the game is over and the player is essentially entirely transparent. Over the course of the game, the player is introduced to an array of data monitoring procedures used across the web, as well as potential counter-action, which can and should be taken in everyday life, just as much as in the game. In reality we do not have a restart option, after all.
This project consists of a mock announcement/teaser trailer for the game. Hope you enjoy.
